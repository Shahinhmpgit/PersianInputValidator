
# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in PersianInputValidator, please report it responsibly.

Please do not publish sensitive vulnerability details in a public issue before the maintainers have had a reasonable opportunity to review the report.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository maintainer through an available private communication channel.

Include the following information when possible:

- A clear description of the suspected vulnerability.
- The affected file, method, or component.
- Steps to reproduce the issue.
- A minimal proof of concept that does not expose real personal data.
- The potential impact and any suggested mitigation.

## Response and Disclosure

Reports will be reviewed as time and resources permit. Please do not assume that a report has been received or resolved until you receive confirmation.

No response time or remediation deadline is guaranteed.

## Scope

Security reports may include issues involving unexpected input handling, crashes, incorrect validation behavior, or other defects with a demonstrable security impact.

A format validator does not replace server-side authorization, identity verification, or other application security controls.

## Supported Versions

The project is under active development. There is no stable release or formal long-term support policy yet.
